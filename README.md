# Проект "Live flight tracker"

## Описание
Проект "DataSearch" - это приложение для поиска информации о самолетах в воздушных пространствах тех стран, которые вы выберете.

## Установка

1. Клонируйте репозиторий
git clone https://github.com/ksen6423/CourseWork3
2. Установите зависимости
pip install -r requirements.txt


## Использование

1. Созданы классы для работы с API для получения информации о самолетах
2. Спроектированы таблицы в БД PostgreSQL для хранения полученных данных о странах и самолетах.
3. Создан класс DBManager для работы с данными в БД.
4. Реализована функция для работы с пользователем
